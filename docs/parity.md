# Feature parity with PowerPoint

The summary is generated by `cargo xtask parity` from the table at the bottom of this file (edit a
row, re-run). Rows come from the black-box feature catalogue of PowerPoint for Mac (menus, ribbon
tabs, dialogs and panes observed in the running app — no Microsoft code, documentation assets or
images were copied).

Each row is scored **D** (done), **P** (partial: works but lacks options, UI or fidelity) or **M**
(missing), weighted by priority (**P0** core = 3, **P1** = 2, **P2** = 1). Out of scope: Microsoft
365 cloud services (co-authoring through OneDrive, Copilot, stock images, Designer's online service,
Live Presentations), add-ins and VBA macros.
