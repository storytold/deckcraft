Download the file for your system from the [latest release](https://github.com/storytold/deckcraft/releases/latest) and install it, or install DeckCraft from ArtCraft Launcher. In file names, `<version>` stands for the version number, for example `0.7.0`.

## Windows 11

1. Open the [latest release](https://github.com/storytold/deckcraft/releases/latest).
2. Download `deckcraft-<version>-windows-x64.msi`. It fits most PCs (64-bit Intel and AMD).
3. Run the file and follow the installer.
4. Start **DeckCraft** from the Start menu.

The installer puts DeckCraft in the `DeckCraft` folder inside Program Files for all users and adds a Start menu shortcut. It also lists DeckCraft under "Open with" for `.pptx`, `.potx` and `.ppsx` files without making it your default app for them.

Other Windows builds on the release page:

| PC                                 | Installer                               | Portable (no install)                            |
|------------------------------------|-----------------------------------------|--------------------------------------------------|
| 64-bit Intel or AMD                | `deckcraft-<version>-windows-x64.msi`   | `deckcraft-<version>-windows-x64-portable.zip`   |
| Arm (Snapdragon and other Arm PCs) | `deckcraft-<version>-windows-arm64.msi` | `deckcraft-<version>-windows-arm64-portable.zip` |
| 32-bit Windows                     | `deckcraft-<version>-windows-x86.msi`   | `deckcraft-<version>-windows-x86-portable.zip`   |

The README says the installers and executables are code-signed, and that `SHA256SUMS.txt` on the release lists a checksum for every file.

If the window flashes and closes, see [DeckCraft closes right after it starts](../troubleshooting/app-closes-at-startup.md).

## macOS

1. Download `deckcraft-<version>-macos-universal.dmg`. It works on Apple silicon and Intel Macs and is signed and notarized.
2. Open it and drag DeckCraft to Applications.

## Install with ArtCraft Launcher

ArtCraft Launcher lists DeckCraft in its app catalog under "Presentations and slide shows". Open the launcher and install DeckCraft from there. Steps are in the launcher docs: [ArtCraft Launcher](https://getartcraft.com/docs/craft-launcher).

## Linux, FreeBSD and the web

The release also has builds for Linux, FreeBSD and the web. They are listed in the [README](https://github.com/storytold/deckcraft#downloads).
