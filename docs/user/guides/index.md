Each guide covers one task.

- [Build a deck](build-a-deck.md): pick a theme, add slides with layouts, change the look later.
- [Open and save PowerPoint files](open-and-save-powerpoint-files.md): open a `.pptx`, save as `.pptx` or as a DeckCraft file.
- [Add a slide transition](add-a-slide-transition.md): choose an effect, set its timing, apply it to every slide.
- [Present your deck](present-your-deck.md): play the show, use presenter view, move around with the keyboard.
- [Export a deck to PDF](export-to-pdf.md): slides, notes pages or handouts.
