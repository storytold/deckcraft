DeckCraft is a presentation app for building slide decks and presenting them. It is a free, open-source alternative to Microsoft PowerPoint, written from scratch in Rust, and it opens and saves PowerPoint `.pptx` files.

You can build decks with slide masters, layouts, themes, shapes, pictures, tables, charts, transitions and animations, then play them full screen with a presenter view. There is no subscription and no cloud account. DeckCraft is in alpha, so some PowerPoint features are still missing.
