title: Is DeckCraft finished?
description: DeckCraft is in alpha; the README gives its own measure of how much of PowerPoint it covers.
order: 30

---

No. DeckCraft is in alpha, heading for beta. Expect missing features and rough edges.

The README measures it against PowerPoint: about 79% of PowerPoint's features by breadth (92% of the core ones, measured), and about 55% of the way to replacing PowerPoint for real work (an estimate). The [roadmap](https://github.com/storytold/deckcraft/blob/main/ROADMAP.md) and the list of known gaps are in the repository.

Sources: the Roadmap section of the [README](https://github.com/storytold/deckcraft#roadmap).
